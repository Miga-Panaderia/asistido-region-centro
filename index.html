CONFIGURACIÓN PROTEGIDA
La carga del archivo madre de ventas y la Fecha de inicio quedan bloqueadas fuera de este menú.
☁ ACCESOS FIREBASE POR SUCURSAL
Creá o restablecé el acceso online de cada sucursal. El usuario ingresa con Sucursal + PIN. El PIN puede tener desde 3 dígitos; MIGA utiliza una credencial técnica de Firebase por detrás.
Dejá el campo vacío si no querés modificar esa sucursal. El PIN debe ser numérico y tener como mínimo 3 dígitos. El PIN no queda guardado en el navegador.
🔐 SEGURIDAD ADMIN GENERAL
Cambiá la contraseña del Administrador General directamente en Firebase. El UID y los permisos del sistema no se modifican.
Por seguridad, MIGA vuelve a validar la contraseña actual antes de realizar el cambio. La nueva contraseña no se guarda en el navegador.
☁ FIREBASE · SINCRONIZACIÓN
Verificando conexión con Firebase…
Esta primera etapa sincroniza los datos cuando ingresás como Administrador General. El acceso de cada sucursal a Firebase se habilitará en la siguiente etapa.
Sincronización automática: inactiva
La primera vez, usá Subir datos actuales a Firebase desde la PC que tenga la configuración correcta. Después, MIGA podrá traer y actualizar esos datos desde otros dispositivos.
RESPALDO Y RESTAURACIÓN
Generá una copia completa de la configuración de MIGA. Incluye todas las sucursales guardadas en este navegador, coeficientes, cronogramas, elaboradoras, destinos, teléfonos, contraseñas, preferencias y las ventas que estén cargadas.
Respaldo mensual Verificando estado…
Restaurar desde respaldo reemplaza la configuración MIGA de este navegador por la contenida en el archivo. “Restaurar sucursal actual” solo vuelve esa sucursal a sus parámetros iniciales.
WHATSAPP ELABORADORAS
Configurá el número de cada sucursal elaboradora. Usar código de país y área, solo números. Ejemplo Argentina: 5492991234567.
MI CONTRASEÑA · SUCURSAL
Podés reemplazar la clave inicial de tu sucursal. La nueva contraseña será la que se use para ingresar a esta sucursal y para desbloquear su Menú Admin.
PADRÓN DE REFERENCIAS POR ZONA
Cada zona tiene un padrón maestro independiente. Excel masivo: Articulo | Descripción | Marca | Aptitud | U/M | Bto. Las sucursales de la zona heredan automáticamente ese padrón. Las referencias nuevas ingresan con Coef. 0% y cronograma sin días activos; las existentes conservan su Coef. y Cronograma.
