🔄 CICLO DE PRODUCCIÓN
Al iniciar un ciclo, MIGA genera primero una línea base y respaldo por zona y sucursal. El ZIP incluye JSON para restauración y Excel para consulta humana, y esa copia permite comparar al cierre cómo cambió cada cronograma.
El respaldo se toma antes de poner coeficientes en 0%. El ZIP guarda JSON restaurable + Excel legible por zona, con una hoja por sucursal. El reporte final compara el cronograma actual contra esa línea base.
☁ ACCESOS FIREBASE POR SUCURSAL
Creá o restablecé el acceso online de cada sucursal. El usuario ingresa con Sucursal + PIN. El PIN puede tener desde 3 dígitos; MIGA utiliza una credencial técnica de Firebase por detrás.
Dejá el campo vacío si no querés modificar esa sucursal. El PIN debe ser numérico y tener como mínimo 3 dígitos. El PIN no queda guardado en el navegador.
🔐 SEGURIDAD ADMIN GENERAL
Cambiá la contraseña del Administrador General directamente en Firebase. El UID y los permisos del sistema no se modifican.
Por seguridad, MIGA vuelve a validar la contraseña actual antes de realizar el cambio. La nueva contraseña no se guarda en el navegador.
☁ FIREBASE · SINCRONIZACIÓN
Verificando conexión con Firebase…
Esta primera etapa sincroniza los datos cuando ingresás como Administrador General. El acceso de cada sucursal a Firebase se habilitará en la siguiente etapa.
Sincronización automática: inactiva
La primera vez, usá Subir datos actuales a Firebase desde la PC que tenga la configuración correcta. Después, MIGA podrá traer y actualizar esos datos desde otros dispositivos.
🛟 RECUPERACIÓN DE EMERGENCIA
Herramientas para recuperar MIGA ante una carga incorrecta o una modificación accidental. El respaldo oficial del ciclo se genera desde Ciclo de Producción.
Restaurar una sucursal: elegí directamente la zona y la sucursal sin salir del Administrador General.
Esta acción restablece parámetros, coeficientes y cronograma de la sucursal elegida. No modifica las ventas del archivo madre. Para volver exactamente al estado de inicio de un ciclo, conservá el respaldo generado al iniciar ese ciclo.
WHATSAPP ELABORADORAS
Configurá el número de cada sucursal elaboradora. Usar código de país y área, solo números. Ejemplo Argentina: 5492991234567.
MI CONTRASEÑA · SUCURSAL
Podés reemplazar la clave inicial de tu sucursal. La nueva contraseña será la que se use para ingresar a esta sucursal y para desbloquear su Menú Admin.
PADRÓN DE REFERENCIAS POR ZONA
Cada zona tiene un padrón maestro independiente. Excel masivo: Articulo | Descripción | Marca | Aptitud | U/M | Bto. Las sucursales de la zona heredan automáticamente ese padrón. Las referencias nuevas ingresan con Coef. 0% y cronograma sin días activos; las existentes conservan su Coef. y Cronograma. También podés seleccionar varias referencias para eliminarlas juntas o vaciar todo el padrón de la zona. El padrón se mantiene automáticamente ordenado alfabéticamente por Descripción. La carga del cronograma utiliza guardado agrupado: los clics se muestran al instante y se sincronizan juntos después de una breve pausa.
